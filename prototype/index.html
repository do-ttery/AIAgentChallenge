페이지 교체 · 예상 문제 1 / 10

Q1 · 객관식

TLB(Translation Lookaside Buffer)에 대한 설명으로 옳은 것은?

✗ 오답 — 그런데 여기서 끝이 아니에요

TLB miss와 page fault를 혼동 → “주소 변환 흐름” 이해가 부족합니다.

TLB는 주소 변환 캐시, page fault는 페이지가 메모리에 없을 때 — 둘은 다른 층에서 일어나요.

▶ 주소 변환 흐름 복습가상주소 → TLB → 페이지 테이블 → 물리주소 3:00
✓ 정답

맞아요 — TLB는 주소 변환 항목을 캐싱하는 장치예요.

이 개념은 이미 이해했네요. 다음 약점으로 넘어갈게요.

재시험 · 유사 문제

가상주소 변환 중 TLB에 항목이 없으면(TLB miss) 다음에 일어나는 일은?

✓ 극복!

주소 변환 흐름을 잡았어요. TLB miss ≠ page fault 를 구분했습니다.

‘주소 변환 흐름’ 숙련도 40 → 70 · 상태: 학습중 → 극복

아직 — 더 쉬운 설명으로

TLB miss는 “주소를 못 찾음(변환 실패)”이지 “페이지가 없음”이 아니에요. page fault와는 다른 단계예요. 다시 볼까요?
