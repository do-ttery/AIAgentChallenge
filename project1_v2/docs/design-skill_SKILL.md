# 안개 걷기 에이전트 — 디자인 스킬

## 무드

게임의 fog of war 감성을 가진 개발자 도구. 다크 테마 고정.
죄책감을 주는 대시보드가 아니라, 지도를 밝혀가는 탐험의 느낌.
딱딱한 관리자 페이지 금지 — 어둡지만 따뜻하고, 정보는 적게, 은유는 진하게.

## 색 (CSS 변수 — 이 값만 사용, 임의 색 추가 금지)

```css
:root {
  --bg: #0f1420;            /* 페이지 배경 (밤하늘) */
  --surface: #1a2133;       /* 카드·타일 배경 */
  --surface-deep: #141a2a;  /* 상단바·코드 블록 배경 */
  --border: #2a3348;        /* 기본 테두리 */
  --border-hover: #4f7cff;  /* 호버 시 테두리 */
  --primary: #4f7cff;       /* 주 액션, 게이지 시작 */
  --primary-hover: #6b90ff;  /* 주 버튼 hover (accent 아님 — 혼용 금지) */
  --accent: #7fd4ff;        /* 게이지 끝, 강조 텍스트 */
  --text: #e8ecf4;          /* 본문 */
  --text-muted: #8b94a7;    /* 보조 텍스트 */
  --clear: #6fce93;         /* 밝음(걷힌) 상태 */
  --clear-bg: #1a2b22;      /* 걷힘 카드 배경 */
  --wrong: #ff9db1;         /* 오답 강조 */
  --wrong-bg: #2b1e24;      /* 오답 해설 배경 */
  --radius: 12px;           /* 카드·버튼 공통 (타일은 14px) */
  --gap: 16px;              /* 기본 간격 (작은 간격 8px, 섹션 24px) */
}
```

## 타이포

- 본문: Pretendard, 15px, line-height 1.6
- 제목: 26px / 19px, weight 700
- 코드·파일명·모듈명: monospace 13~15px — 파일 경로는 반드시 monospace
- 보조 정보: 13px, --text-muted

## 핵심 패턴 (이 제품만의 문법)

1. **안개 표현**: 안개 상태 요소는 반투명 밝은 오버레이(rgba(190,205,230,0.2~0.45) 그라데이션) + "?" 아이콘. blur 남용 금지 — 오버레이가 기본.
2. **밝음 표현**: --clear 색 + ✓. 걷힌 것은 자랑스럽게, 안개는 무섭지 않게.
3. **장악률 게이지**: 항상 상단바에 노출. linear-gradient(90deg, --primary, --accent). 이 제품의 점수판이므로 어떤 화면에서도 숨기지 않는다.
4. **상태는 색+아이콘 동시 표기**: 색만으로 구분 금지 (❓/✓/✗ 병기).
5. **오답은 혼내지 않는다**: --wrong 계열은 부드럽게, 해설 톤은 "아까워요" — 빨간 경고색(#ff0000류) 금지.

## 컴포넌트 규칙

- 버튼: padding 13px 34px, --radius, 주 버튼은 --primary 배경 (hover: --primary-hover) / 보조 버튼은 투명 배경 + --border 테두리. --accent는 텍스트·게이지 강조 전용, 버튼 배경에 쓰지 않는다
- 카드·타일: --surface 배경 + --border 1px, hover 시 --border-hover
- 상단바: --surface-deep, 로고 · 장악률 게이지 · 설정(⚙) 순서 고정

## 하지 말 것

- 라이트 테마 변형 금지 (다크 온리)
- 외부 UI 라이브러리(MUI, antd 등) 금지 — 직접 CSS
- 그림자·글로우·네온 남용 금지 (걷힘 연출 순간에만 허용)
- 이모지 남발 금지 — 허용된 것: ❓ ✓ ✗ ⚙ 🌫 ✨ ☀
- 한 화면에 정보 밀도 높이기 금지 — 지도 화면의 주인공은 타일, 나머지는 조연
