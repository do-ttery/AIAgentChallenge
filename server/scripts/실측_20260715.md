## 🔴 T-05 핵심 측정 — 텀블 휴지기 최대 지속 시간

> 종료 판정("0W 유지")은 이 값보다 넉넉히 길어야 함. 세탁 중 10W dip을 종료로 오판 방지.

**최대 휴지기 = ~10초 (육안, 탈수+헹굼 구간)**
- 탈수+헹굼 중엔 휴지기 거의 없음. 있어도 10초 넘지 않음.
- → 종료 "유지" 시간 후보 = **최소 30초, 안전하게 60초** (10초 dip을 종료로 오판 방지)
- → 폴링 5초 충분 (dip 10초 > 5초라 폴링이 잡음)

⚠️ 아직 확인 못 한 것: **세탁(초반) 구간**의 휴지기가 10초보다 길 수 있음(불림 등).
   진짜 종료 순간(7W 유지)을 꼭 포착해 dip과 구분할 것.

## 코스 · 소요 시간

- 코스: **표준세탁 (STANDARD WASH)** — 찬물, 20kg 5,000원
- 구조: **세탁 1회 + 헹굼 3회 + 탈수** (사진 확인)
- 소요: **35분** (3:16 시작 → 3:51 종료, 앱 표기와 실측 일치)

## 소리 이벤트 손기록

- **종료 순간: 종료음과 거의 동시에 전력 하강 → 9W → 몇 초 후 7W 안착, 안 올라옴**
  - 전력과 소리가 거의 동시 (전력 기준 판정이 소리보다 늦지 않음 → 좋음)
  - 세탁 중 dip은 다시 200W로 올라옴 / 종료는 안 올라옴 → 명확히 구분됨

## ⚠️ 상태 머신 재검토 사항 — 중간 탈수 (헹굼 3회)

표준세탁이 "헹굼 3회 + 탈수"라, **각 헹굼 끝의 배수·탈수에서 ~800W 스파이크가 여러 번 튈 가능성**이 있다.
현재 상태 머신은 `RUNNING → SPIN → DONE`으로 탈수를 마지막 1회로 가정 → 중간 탈수에서 조기 SPIN 전이 위험.
- 종료 오판은 안 남 (`DONE`은 20W 60초 유지 필요, 중간엔 헹굼으로 전력 계속 올라옴)
- **✅ 결정 완료 (2026-07-16)**: 첫 스파이크(500W 이상)에서 `RUNNING→SPIN` 전이 후 계속 유지. 역전이(`SPIN→RUNNING`) 없음. 상세는 CLAUDE.md State Machine 참고. 다음 CSV 실측으로 스파이크 패턴 재확인 예정이나, 코드 착수 블로커는 아님
