# 작업 분해 체크리스트

핵심 기능 2개 기준 작업 분해. 잘게 쪼갤수록 Agent 성공률·검증 용이성이 올라간다.

## 1주차 — 수거 알림 (핵심 ①)
- [ ] QR → 세탁 정보 페이지 진입 화면 (기계 번호 표시)
- [ ] 남은 시간 입력 폼 (숫자 + '분')
- [ ] 알림 설정 완료 → 종료 시각 계산/저장
- [ ] 완료 시각 도달 감지 로직
- [ ] 웹 푸시 알림 전송 (권한 요청 포함)
- [ ] 수거 완료 버튼 → 상태 갱신

## 2주차 — 방치 방지 (핵심 ②)
- [ ] 점주 관리자 화면: 기계 목록 + 상태 뱃지
- [ ] 완료 후 경과 시간 계산
- [ ] '방치 의심' 판정 기준 적용 (기준값 TBD)
- [ ] 방치 의심 기계 하이라이트 표시
