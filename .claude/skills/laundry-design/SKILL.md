# 빨래집사 Design Skill

## Goal

무인빨래방 운영을 돕는 AI Agent 서비스.
서비스명은 빨래집사이다.

AI는 친근하지만
관리 서비스로서 신뢰감을 준다.

수치·토큰의 원본은 `design-system.md`. 충돌 시 그 문서를 기준으로 한다.

## Character

항상 같은 고양이를 사용한다.
변형 금지.

공식 원본 이미지
- 확정 전(현재): 아래 텍스트 스펙을 기준으로 생성·검증한다
- 확정 후: `assets/mascot.png`만 사용한다 — 재생성·재해석 금지 (이미지 확정 시 이 줄을 갱신할 것)

특징
- 크림색 얼굴
- 주황 귀

- 남색 앞치마
- 작은 미소

표정
😀 기본 / 😊 환영 / 😎 성공 / 🤔 생각 / 😢 오류 / 😮 알림

포즈

## Domain Rules (빨래집사 고유 — 반드시 적용)

1. 예상 시각은 점이 아니라 **범위**로 표기한다 — "18:45~18:55"
2. **자동 처리 = Success색 / 사장님 개입 필요 = 방치·Warning색**
3. 소비자 화면은 **정보 1가지**(내 세탁 상태)만 크고 단순하게, 관리자 화면은 정보 + **의사결정**
4. 문구는 고객을 비난하지 않는다 — "방치하셨습니다" ❌ → "찾아가지 않은 세탁물이 있어요" ⭕

## UX Rule

복잡한 설명은 숨긴다.

## Screen Rule

### 고객 화면

| 화면 | 핵심 규칙 |
|---|---|
| QR 랜딩 | 기계 번호 + 현재 상태가 최상단. 알림 신청 버튼이 유일한 Primary Action. 미신청도 상태 확인 가능함을 안내 |
| 진행 화면 | 종료 예상은 범위로. 상태 배지 + 진행 단계 표시. 정보는 이 1가지뿐 |
| 완료 / 방치 상태 | 완료: 수거 안내. 방치(다음 손님 시점): 비난 없는 문구 + 선반 이동 가이드 |

### 관리자 화면

| 화면 | 핵심 규칙 |
|---|---|
| 대시보드 | 요약 수치(전체/가동/방치/확인 필요) → 기계 카드 → 처리 내역 순. 자동 처리는 Success색, 개입 필요는 방치색으로 구분 |
| 승인 대기함 | UI 자리만 (향후 기능 표시, 버튼 비활성). 대시보드 안에 위치 |

## Never

- SF 느낌 금지
- 사이버펑크 느낌 금지
- 네온 컬러 금지
- 복잡한 그래프 금지
- 어두운 테마 금지
- **고객 화면의 상태 표시에 빨강 금지** (방치 포함 — 빨강은 관리자 오류·파괴적 액션만)
- 새 캐릭터 생성 금지, 마스코트 변형 금지
- 관리자 화면에 "~냥" 말투 금지

## Verification Checklist (작업 후 자가 검증 — 전부 ☑ 후 제출)

- [ ] 현재 상태(배지·시간)가 화면에서 가장 먼저 읽히는가
- [ ] 예상 시각이 범위로 표기됐는가
- [ ] 상태 색이 위 표의 hex와 정확히 일치하는가
- [ ] 고객 화면에 빨강이 없는가
- [ ] 자동 처리=Success / 개입 필요=방치색 구분이 지켜졌는가
- [ ] 화면당 Primary Action이 1개인가
- [ ] 문구에 고객 비난 표현이 없는가
- [ ] 관리자 화면에 "~냥" 말투가 없는가
- [ ] 마스코트가 스펙(크림 얼굴·주황 귀·오른눈 AI 렌즈·남색 앞치마)과 일치하는가
- [ ] 네온·다크·SF 요소가 없는가
- [ ] 8pt 그리드·라운드(카드 24/버튼 18)가 지켜졌는가
